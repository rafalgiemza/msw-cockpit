✅ Manual Testing Checklist

  1. Enable the controls: Click the button below or run in console:
    localStorage.setItem("MSW_COCKPIT__ENABLED", "true")
  2. Check for trigger button: Look for a floating 🎭 button in the bottom-right corner
  3. Click trigger button: Modal should open with smooth animation
  4. Select scenarios: Click different scenarios to test
    • Default - Normal state
    • Error - Error state (with ❌ icon)
    • Loading - Loading state (with ⏳ icon)
    • Empty - Empty state (with 📭 icon)
  5. Check URL updates: URL should update with ?scenario=error when you select a scenario
  6. Test browser navigation:
    • Click browser back button - scenario should revert
    • Click browser forward button - scenario should restore
  7. Test keyboard:
    • Press Tab to navigate scenarios
    • Press Enter to select
    • Press Escape to close modal
  8. Click outside modal: Should close the modal
  9. Check styles isolation: Controls should look good and not affect page styles
  10. Test different positions: Use buttons below to test different positions
