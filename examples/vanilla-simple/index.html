🎭 MSW Demo Controls - Simple Example

📝 How to use:

  1. Open browser DevTools console
  2. Run this command to enable the controls:
    localStorage.setItem("MSW_DEMO_CONTROLS_ENABLED", "true")
  3. Reload the page
  4. Look for the floating 🎭 button in the bottom-right corner
  5. Click it to switch between scenarios!

About This Example

This is a simple demonstration of the MSW Demo Controls library. We've configured three scenarios: default, error, and loading.

Configuration Used

import { enableMockControls } from 'msw-demo-controls';

enableMockControls({
  scenarios: ['default', 'error', 'loading'],
  onChange: (state) => {
    console.log('Scenario changed:', state);
    // Update UI
  }
});
